# Contributing

## Development

1. Open the project in your editor.
2. Make a focused change to note creation, editing, storage, or presentation.
3. Test create, edit, delete, and reload behavior in a modern browser.
4. Check that the responsive layout still works.

## Quality Checklist

- Preserve CRUD behavior.
- Keep stored note data valid JSON.
- Handle empty input safely.
- Avoid rendering untrusted note text as executable HTML.
- Test persistence after refreshing the page.

## Pull Requests

Describe the change, expected behavior, and browser testing performed.
